# Configuración de Mapeo de Usuarios para Importación Excel

## ¿Cómo funciona la auto-creación de usuarios?

Cuando se importa un Excel, el sistema puede automáticamente:
1. **Buscar usuarios existentes** por nombre
2. **Crear nuevos usuarios** si no los encuentra
3. **Asignar roles y puestos** según el contexto

## Configuración de FieldMapping

### Ejemplo 1: Gerente de Ventas (con auto-creación)

```javascript
await prisma.fieldMapping.create({
  data: {
    sourceAreaId: "area-diseno-id",
    sourceField: "Gerente de Ventas",           // Columna en Excel
    targetField: "salesManagerId",              // Campo en BD
    targetTable: "staging_projects",
    transformation: "USER_LOOKUP_OR_CREATE:sales_manager", // ← Clave aquí
    isRequired: false,
    description: "Auto-crea usuarios con rol COORDINADOR para ventas"
  }
});
```

## Ventajas del Sistema

### ✅ **Automático**
- No necesitas crear usuarios manualmente antes de importar
- El sistema identifica qué tipo de usuario es según la columna

### ✅ **Inteligente**
- Busca primero si el usuario ya existe
- Solo crea usuarios nuevos cuando es necesario
- Asigna roles apropiados según el puesto

### ✅ **Trazeable**
- Cada usuario auto-generado queda marcado como tal
- Puedes generar reportes de usuarios creados
- Se guarda el password temporal para comunicarlo

### ✅ **Configurable**
- Puedes modificar los mapeos sin cambiar código
- Agregar nuevos tipos de puestos es simple
- Cambiar roles por tipo de puesto es fácil

## Configuración Inicial Recomendada

Para configurar el sistema por primera vez:

```sql
-- 1. Configurar mapeo para Gerente de Ventas
INSERT INTO field_mappings (source_area_id, source_field, target_field, target_table, transformation, description)
VALUES (
  'area-id',
  'Gerente de Ventas',
  'salesManagerId',
  'staging_projects',
  'USER_LOOKUP_OR_CREATE:sales_manager',
  'Auto-crea gerentes de venta'
);

-- 2. Configurar mapeo para Ejecutivo de Ventas
INSERT INTO field_mappings (source_area_id, source_field, target_field, target_table, transformation, description)
VALUES (
  'area-id',
  'Ejecutivo Venta',
  'salesExecutiveId',
  'staging_projects',
  'USER_LOOKUP_OR_CREATE:sales_executive',
  'Auto-crea ejecutivos de venta'

-- 3. Configurar otros puestos...
```

## Flujo Completo

1. **Configurar mapeos** para cada columna de persona en Excel
2. **Importar Excel** normalmente
3. **Sistema auto-crea usuarios** que no existen
4. **Revisar reporte** de usuarios creados
5. **Comunicar passwords temporales** a los nuevos usuarios
6. **Usuarios cambian password** en primer login

Este sistema elimina la necesidad de crear manualmente cientos de usuarios antes de importar datos desde Excel.
